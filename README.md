# HR Database Dashboard Analysis

## Overview
This project was developed during the NTI Training Program=.

The dashboard provides insights into HR data including employee distribution, departments, salaries, performance, and workforce trends.

## Tools Used
- Excel
- Data Cleaning
- Data Visualization
- Data Analysis

## Key Insights
- Employee distribution across departments
- Salary and compensation analysis
- Workforce demographics analysis
- Performance and employee trends
- HR KPIs visualization

## Dashboard Features
- Interactive visualizations
- KPI cards
- Department filters
- Employee analytics
- Dynamic charts
